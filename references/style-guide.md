# 搭配样式卡 · 风格指南

视觉基准见 `assets/reference-card.jpeg`(经典带标签版)与用户提供的
小红书参考图(竖版无标签版)。生成任何搭配卡前先对照本指南。

## 小红书竖版(默认,compose_card_xhs.py)

- 画布 1152×2048(9:16),纯白底,无渐变、纹理、边框
- **无单品标签**:单品本身即主角,仅底部一行可选小号题注
  (细体、暖灰 `#968E80`,位置约为画幅高 96.5%)
- **杂志剪贴感层叠**:
  - 绘制顺序固定:下装 → 连衣裙/上装 → 丝巾 → 鞋 → 袜 → 帽 → 首饰 → 包(最上层)
  - 连衣裙/上装占左上大半幅(填充比 1.0),下装右侧长条,
    包居中偏右压在大件之上(填充比 1.04,刻意压出盒外),
    鞋左下,帽/首饰右上角(同场时首饰下移让位)
  - 每件单品带柔和投影(blur 18、下移 16、不透明度 90)
    和确定性微旋转(±3°,由单品 id 哈希决定,同一件每次角度一致)
- **水印擦除**:AI 美化图左下角有「AI生成」半透明水印(近白灰色、
  alpha 40–235,固定在 x<24%、y>83% 角落),脚本在 trim 前自动
  将该角落匹配像素的 alpha 置 0。衣服本体即使白色也多为不透明
  (alpha 255),且主体居中不伸进角落,误伤风险极低;若某件单品
  恰好伸进左下角且为浅色,人工复核该件

## 经典 3:4 带标签版(compose_card.py)

### 画布

- 纯白背景 `#FFFFFF`,无任何渐变、纹理、边框
- 默认 3:4 竖版(1200×1600);小红书/公众号封面同比例可直接用
- 单品之间允许轻微叠压,不描边、不加投影

### 排版规则(相对位置,compose_card.py 已内置)

| 槽位 | 位置 | 相对大小(画幅) |
|------|------|----------------|
| 上装 / 外套 | 左上,靠上 | 宽 ≤ 44%,高 ≤ 34% |
| 连衣裙 | 居中 | 高 ≤ 62% |
| 下装 | 中心偏右下,视觉锚点 | 高 ≤ 66%(全卡最大件) |
| 包 | 左下 | 宽 ≤ 28% |
| 鞋 | 右下 | 宽 ≤ 28% |
| 帽子 / 丝巾 | 右上 | 宽 ≤ 30% |
| 首饰 / 配饰 | 右侧中部,小尺寸点缀 | 宽 ≤ 20% |
| 袜子 | 鞋附近 | 宽 ≤ 14% |

- 同槽位多件:水平错开并整体缩小(脚本自动处理)
- 一张卡 4–7 件最佳,不要超过 8 件

### 标签

- 每件单品配一行标签:品牌名(大写)或「品牌 + 品类」
- 上装/帽子/丝巾标签在图上方;下装/包/鞋/首饰标签在图下方
- 深灰黑 `#1A1A1A`,字号约为画幅高的 1/55,居中对齐
- 标题(可选)放左上角,浅灰 `#787878`,小字

## 棚拍级单品图 (make_studio_cards.py)

录入美化后, 可选生成统一的棚拍级展示图 (card 图), 用于预览墙或独立展示。

### 画布规格
- 1500×1500 正方形画布, 奶油米色背景 `#F5F1E8`
- 内边距 8%, 底部 160px 标签区域
- 单品居中放置, 带柔和投影 (blur 12、下移 6、不透明度 20)

### 处理管线 (两条路径)

**路径 A: AI 平铺图 (优先)**
1. 裁掉底部 6% 区域 (去除 AI 水印/文字)
2. 用 rembg 精准去背景 (可处理水彩/渐变/艺术背景)
3. 去白边光晕 (decontaminate_edges)
4. 边缘羽化 (GaussianBlur radius=0.8)
5. 阴影压制 (strength=0.45)
6. 轻度色彩增强 (Color ×1.05, Brightness ×1.03, Contrast ×1.04)
7. 锐化 (UnsharpMask radius=1.0, percent=110)

**路径 B: rembg 抠图 (回退)**
1. 去白边光晕 (decontaminate_edges)
2. 边缘羽化 (radius=0.6)
3. 自动色阶 (直方图拉伸)
4. 阴影压制 (strength=0.60)
5. 色彩增强 (Color ×1.12, Brightness ×1.06, Contrast ×1.06)
6. 锐化 (UnsharpMask radius=1.5, percent=130)

### 底部标签
- 有品牌: 粗体, 深棕色 `#373026`
- 无品牌: 常规体, 灰棕色 `#6E6455`, 格式「品类 · 样式」
- 标签上方有浅色分隔线 (15%~85% 画布宽度)
- 字号根据文字长度自适应 (8字→72px, 12字→62px, 16字→54px, 20字→46px, 更长→38px)

### 预览墙 (make_contact_sheet.py)
- 4 列网格, 单品图 480×480, 标签区 50px
- 奶油米色背景 `#F5F1E8`, 间距 16px, 外边距 50px
- 每张图下方附带品牌(粗体28px)或样式(常规24px)标签

## 单品图要求

- 透明底 PNG 最佳;白底 JPG 也可(脚本会贴到白底上)
- 单品占图比例 ≥ 60%,正/侧面平视角度,无人体、无衣架杂物
- 保持单品本身的立体褶皱与垂坠感(参考图中 T 恤、阔腿裤均为立体平铺)

## 抠图备选(rembg 不可用时)

按优先级:
1. 当前 agent 平台自带的图像编辑/生成能力,提示词:「去除背景,只保留单品本身,输出透明底 PNG,保持立体褶皱,白底影棚产品图风格」
2. iOS/安卓相册长按主体拷贝,或系统「隔空投送抠图」
3. remove.bg / 稿定抠图等在线工具

抠图质量差(边缘毛糙、残留背景)时告知用户,建议重拍:纯色背景、光线均匀、单品平铺。

## 美化(去皱板正)

抠图后默认再做一步美化,让实拍衣服的褶皱减少、形态整洁板正,
接近电商平铺 catalog 质感。首选 AI image-to-image 重绘(提示词模板
与漂移修正措辞见 SKILL.md 工作流第 1 步),限流就间隔 20–30 秒重试;
无 AI 能力时用 `scripts/beautify_item.py` 做本地去皱(双边滤波频率
分离,轻褶有效、深褶有限)。重绘件必须逐件对照原图审查保真度。
AI 图左下角会带「AI生成」合规水印:保留在单品图里没问题,
合成小红书卡时 compose_card_xhs.py 会自动擦除(规则见上文),
经典版若标签排版被水印干扰,也可调用同一函数擦除后再合成。
