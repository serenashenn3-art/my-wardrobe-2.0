# 批量上传工作流示例

## 场景: 用户一次上传 20 张衣服照片

1. 用户在 Web 应用中点击「上传单品」按钮
2. 选择 20 张图片(系统支持最多 30 张)
3. 系统为每张图片创建单品卡片:
   - ID 自动递增(从最后一个 ID 继续)
   - 默认 slot: accessory(用户可后续修改)
   - 默认 label: 文件名(去扩展名)
   - 默认 seasons: ["四季"]
4. 上传完成后,用户可以:
   - 在「分类浏览」中逐件修改 slot 分类
   - 在「品牌浏览」中逐件输入品牌名
   - 在「回收」中将不需要的单品移至二手出售或捐赠

## 场景: 用户整理衣橱,将 5 件衣服标记为回收

1. 在「分类浏览」或「品牌浏览」中,点击单品卡片上的「回收」按钮
2. 单品从主列表移除,进入回收列表
3. 在「回收」标签页中:
   - 切换到「二手出售」: 输入原价、出售价格、选择成色和渠道
   - 切换到「捐赠」: 选择捐赠机构和状态
4. 顶部汇总显示: 出售总数 + 预计总收入, 或捐赠总数
5. 可随时点击「移回衣橱」将单品退回主列表
